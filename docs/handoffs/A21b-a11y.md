# A21b Accessibility & Keyboard Navigation Handoff Report

## Deliverables & Keyboard Shortcuts
- **Global Keyboard Shortcut Listener** implemented in `src/app/App.tsx` (ignoring input/select/textarea form fields):
  - `Space`: Toggle time simulation playback (Play / Pause).
  - `ArrowLeft` / `ArrowRight`: Step time backward / forward by 1 hour (or 1 day when holding `Shift`).
  - `1`: Switch center viewport to **3D Moon Globe**.
  - `2`: Switch center viewport to **3D Local Terrain**.
  - `3`: Switch center viewport to **Horizon Panorama**.
  - `m` / `M`: Toggle between **Overview** (plain language) and **Technical** (astrometric frames & vectors) mode.
  - `c` / `C`: Toggle **Comparative Scenario Matrix** overlay.
  - `?`: Toggle **Interactive Guided Tour**.
  - `Escape`: Dismiss open modals (Compare overlay, Tour dialog).
- **A11y Enhancements**:
  - Semantic HTML landmarks (`<header>`, `<aside>`, `<main>`, `<footer>`).
  - ARIA role attributes (`role="tablist"`, `role="tab"`, `aria-selected`, `aria-controls` in `Tabs.tsx`).
  - Accessible high-contrast focus rings (`focus-visible:ring-2 focus-visible:ring-sun-amber/50`).
